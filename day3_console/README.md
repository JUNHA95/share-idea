# 아이디어 콘솔 v2 · 기본필수

## 목적과 범위
Multi AI Agent 프로젝트의 아이디어와 역할을 관리하는 학습용 콘솔입니다. 실제 LLM을 호출하지 않습니다.
PPT 64쪽의 목표 구조를 사용합니다. Python 3.13.x, NumPy 2.3.5, pandas 2.2.3 기준입니다.

## 실행
이 README가 있는 day3_console 폴더에서 가상환경 Python으로 실행합니다.
```text
python -m idea_app.main
python -m idea_app.main --demo
python -m idea_app.main --show
```
--demo는 합성 3건을 생성하며 이미 data/ideas.json이 있으면 덮어쓰지 않습니다. 새 폴더를 쓰려면 `--workspace ./trial_02`를 추가합니다.
메뉴 5는 저장, 메뉴 0은 저장 없이 종료합니다. 처음 파일이 없으면 빈 목록으로 시작합니다.

## 저장 위치
기본 기준 폴더는 `Path(__file__).resolve().parent.parent`인 프로젝트 루트입니다.
JSON: `data/ideas.json`, 보고서: `reports/summary.txt`.
코드 파일과 별개로 상대경로가 바뀌는 일을 막도록 main에서 경로를 만들어 함수에 전달합니다.

## 실패 정책
잘못된 필수 입력은 거부합니다. 손상/키 누락/자료형 오류는 현재 목록과 원본을 보존합니다.
불러오기에 실패한 상태에서는 저장을 차단하고 다시읽기 성공 후 해제합니다.
저장 실패 때 성공 메시지를 출력하지 않습니다. 기본필수는 이름 중복 기능이 필수가 아니며 응용부터 중복을 거부합니다.

## 데이터 계약
name(str), problem(str), roles(list[str]), difficulty(기본필수/응용/심화)를 가진 Dict의 List를 JSON에 저장합니다.
score/role_count는 실습 06의 별도 합성 분석 데이터이며 저장 필수 키가 아닙니다.

## 함수·모듈 책임
models=Idea/레코드 변환, service=등록·검색·상태, storage=파일·검증, analytics=요약, main=메뉴·안내.
io_support는 강사가 제공한 안전 저장 보조 코드로 학습자가 새로 작성할 대상이 아닙니다.
